## Slide 0C — The Compelling Event

### Title
`Code Red | The Compelling Event`

### On Screen

[Flow diagram — see below]

`Shopify Code Red: November 2024 – July 2025`

**Design note:** The flow diagram sits center. The date line anchors below it. Nothing else. The talk track carries the definition.

### Flow Diagram
Five stages, left to right:

| Stage | Type | Label |
|---|---|---|
| Target account | Neutral | Target account |
| Research | Neutral | Research / Public signals |
| Compelling event | Highlighted (purple) | Compelling event / Hypothesis of need |
| Solution fit | Diamond gate (amber) | Solution fit — GO |
| Present hypothesis | Highlighted (teal) | Present hypothesis / You are here |

**Design note:** Diamond gate for Solution Fit signals a deliberate go/no-go decision, not a passive step. Teal on the final node marks current position in the process. The diagram makes the methodology visible without Kevin narrating it line by line.

### Talk Track
> "You will hear me reference a Code Red. In Shopify terms, this is a real event. It is not a planned code freeze before Black Friday or Cyber Monday. It is an unplanned, all-hands effort to stabilize the codebase and clear blockers — improving code quality under pressure. The team executing it does not always recognize that is what they are doing, or how they got there.
>
> The last event ran November 2024 through July 2025. Seven months.
>
> That seven-month window is where this opportunity develops.
>
> The diagram shows where we are in the sales cycle. The account research surfaced the signal. The Code Red is the compelling event and the hypothesis of need. Solution fit was a go. We are here — presenting the hypothesis to the prospect."

**Delivery note:** "Seven months." is a full stop. Let it land before moving to the diagram explanation. The last sentence hands off directly to Slide 1.
